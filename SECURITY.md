# Security Policy

## Supported Versions

Security updates are provided for the latest maintained release of Eii Filament Turnstile.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | Not guaranteed |

## Reporting a Vulnerability

If you discover a security vulnerability in Eii Filament Turnstile, please report it responsibly.

**Email:** info@eiitechsolutions.com

Please include the following information in your report:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The affected package version.
- Any relevant proof of concept or technical details.

Please do not disclose security vulnerabilities through public GitHub issues.

## Our Commitment

We will:

- Acknowledge your report as soon as reasonably possible.
- Investigate the reported vulnerability.
- Work on a fix where necessary.
- Notify you when a security fix is available.

We appreciate responsible disclosure and the efforts of the security community in helping keep this package safe.
